# Материалы для репетитора

Сюда кладутся учебные файлы HSK (txt, md, json, csv, tsv) — репетитор читает их на сервере и берёт из них слова и уроки.
Один файл — до 40 КБ, всего — до 120 КБ. Файл README.md в промпт не попадает.
Для личного пользования можно загрузить файлы прямо в приложении: «Репетитор» → «Настройки репетитора».
