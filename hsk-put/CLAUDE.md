# HSK Путь — контекст проекта для Claude Code

Приложение для изучения китайского с нуля до HSK 6. Пользователь говорит по-русски, цель — жить в Китае и общаться с носителями. Интерфейс полностью на русском. Иероглифы — главный фокус.

## Устройство
- Всё приложение — **один файл `index.html`** (~360 КБ): CSS + данные + логика, без сборки и зависимостей. Не дроби на модули без прямой просьбы: однофайловость — фича (открывается двойным кликом, легко деплоить).
- Шрифты Google Fonts: Golos Text (UI), Noto Sans (пиньинь), Noto Sans SC + PingFang SC (иероглифы, печатный вид без засечек).
- Цвета — токены в `:root`, тёмная тема через `prefers-color-scheme`. Цвета тонов: `--t1…--t5`.
- Рендер: `views.<имя>()` возвращает HTML-строку → `render()`. Клики — делегирование через `data-a="<действие>"` → объект `act` (раздел «СОБЫТИЯ»). Навигация: `go(view, params)`, параметры в `V`.

## Ключевые механики
- **SRS** SM-2: `S.srs[id]={ef,iv,reps,lapses,due}`. Новое слово в повторение: `{ef:2.5,iv:0,reps:0,lapses:0,due:tomorrow()}`.
- **Транскрипция Палладия** (`pallSyl`, `pallW`, `pallHTML`) — русское чтение пиньиня, переключатель в настройках.
- **Озвучка** — Web Speech API zh-CN: `say(text, rate)`.
- **Уровни**: тест 20 вопросов, порог 80% → `S.passed[l]`, открывается следующий уровень.
- **Погружение**: подписи меню заменяются китайскими, когда слово выучено (`NAVZH`, `knownHz`).
- **Спринт 300**: день открывается после «Выучил фразы» прошлого дня; этапы фразы → семьи знаков → сборка → диктант → письмо (12 самых продуктивных новых знаков дня). Правило данных: во фразах дня только слова этого и прошлых дней.
- Геймификация: XP, 9 рангов (秀才…状元), 21 награда, комбо 连对, цель дня.

## Письмо, тесты и репетитор (v2)
- **Распознавание — офлайн.** `REC`, `recPrep/recRank/recMatch/recVerify`: форма знака — направленные признаки по скелету (порядок черт не нужен) + число черт + порядок, когда число черт совпало. Образцы строятся из осевых линий черт `MEDS_SRC` (Make Me a Hanzi, Arphic Public License; 349 знаков приложения), шрифт не нужен. Знак вне набора система назовёт самым похожим из набора.
- **Проверка известного знака** (`recVerify`): `ok` — узнан, `close` — второй по похожести и почти не хуже первого (парные знаки, неровный почерк), `bad` — другой. `close` засчитывается. Менять пороги только вместе с `npm run rec`.
- **Анимация порядка черт** (`animPlay`, `showAnim`): рисует осевые линии кистью с номерами начала черты. Нужна при «Показать ответ» и после ошибки.
- **Экраны:** `views.write` (режим «Пропись» — тетрадь 田字格 со строкой пиньинь; режим «По памяти» — знак или предложение), `views.prac` (чистый квадрат), `views.board` (доска 16:9/9:16, клетки, строка пиньинь; задание `BD.task` — диктант предложения, проверка по клеткам + пиньинь с клавиатуры), `views.pick` («Мои слова»: выбор, `S.sel`), `views.stest` (сессия теста `TS`: карточки, письменный, предложения, письмо знаков, вопросы), `views.tutor` (ИИ-чат).
- **Списки слов HSK 3.0** (`BANK_SRC` → `BANKW`, ids `n<ур>-<знак>`, 10 969 слов, уровень 7 = «7–9»): источник — открытый словарь complete-hsk-vocabulary (список `new`), русские переводы сделаны для приложения. Живут рядом с курсом приложения (HSK 1–2 по темам), не внутри `WORDS`: выбираются во вкладке «Мои слова» (переключатель «Курс приложения / HSK 3.0»), блоками по 20 слов. Образцы для распознавания строятся только для знаков курса и выбранных слов (`recReady(extra)`), ранжирование идёт по этому набору.
- **Состояние:** `S.sel` (выбранные id слов), `S.selp[id][вид]={ok,t}` (результаты по слову), `S.tlog` (журнал тестов). Слово «освоено», если пройдено ≥2 видов тестов (`masteredIds`).
- **Репетитор:** клиент `tuSend` → `POST /api/chat` (`api/chat.js`, Vercel). Ключ `ANTHROPIC_API_KEY` только на сервере; необязательно `ACCESS_CODE`, `ANTHROPIC_MODEL`. Контекст (`tutorCtx`): выбранные и освоенные слова, журнал тестов, все уроки приложения, материалы. Ответ — JSON `{say,test}`; `test.items` бывают `card|quiz|build|write` и запускаются движком `TS` (`tuQueue`). Материалы ученика: папка `materials/` (читает сервер) и загрузка в браузере.
- Тесты: `npm test` (логика, без браузера), `npm run ui` (рисует мышью, поднимает локальный сервер с настоящим `api/chat.js` и подставным «Claude»), `npm run rec` (точность распознавания на искажённых штрихах).

## Платформа
- Вне claude.ai приложение работает на localStorage. Недоступны: старый ИИ-собеседник «Практика», облачная синхронизация, рейтинг (код проверяет `window.claude` и тихо отключает). ИИ-репетитор работает через собственный сервер `api/chat.js`.
- Чтобы вернуть ИИ-практику при самостоятельном хостинге, нужен свой бэкенд-прокси к Claude API (ключ — только на сервере, никогда в `index.html`). Точка подключения — `aiAsk()`; формат ответа `{zh, py, ru, fix, hint, new:[…]}`.

## Правила работы
- После любой правки: `npm test` (данные, сценарий спринта и деление строки на знаки, без браузера); `npm run ui` — рисование мышью на доске, в «Тренировке» и «По памяти»; `npm run rec` — точность распознавания. Перед сдачей визуальных правок: `npm run screens` (десктоп 1280 и телефон 390, проверяет горизонтальный скролл).
- Новые слова — только через данные (`H1/H2`, `UNITS_SRC`, `SPR_SRC`), не хардкодить в экранах. Порядок загрузки важен: `buildUnits()` после `byLvl`, `buildChars()` в конце скрипта, при пересборке — `rebuildAll()`.
- Изменил структуру `S` → добавь миграцию в `normS()`, иначе у пользователя сломается сохранённый прогресс.
- Мобильная версия обязательна: всё проверять на ширине 390 px.
- Тексты интерфейса: русский, коротко, без канцелярита; Пиньинь с тоновыми знаками.
