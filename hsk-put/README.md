# HSK Путь

Китайский от нуля до HSK 6 для русскоязычных: тоны, 100 графем, иероглифы с прописью, тематические уроки, спринт «300 слов за 10 дней», игры, интервальное повторение, письмо без подсказок с офлайн-распознаванием, доска для целых предложений.

## Запуск
- Просто открой `index.html` в браузере, или
- `npm start` → http://localhost:3000

## Проверка
```bash
npm install            # один раз, для скриншотов
npx playwright install chromium
npm test               # логика и данные
npm run screens        # скриншоты в screens/
npm run ui             # письмо: доска, тренировка, «по памяти»
npm run rec            # точность распознавания знаков
```

## Деплой
Статика (`index.html`) плюс одна функция `api/chat.js` для ИИ-репетитора. Проще всего Vercel.
Без сервера всё работает, кроме репетитора. Для репетитора в настройках проекта добавь переменные окружения:
- `ANTHROPIC_API_KEY` — ключ Claude API (обязательно)
- `ACCESS_CODE` — код доступа, чтобы чужие не тратили твой ключ (рекомендуется; вводится в «Репетитор → Настройки»)
- `ANTHROPIC_MODEL` — модель, по умолчанию `claude-sonnet-5-5`

Материалы для репетитора (файлы HSK) кладутся в папку `materials/`.

Данные порядка черт: Make Me a Hanzi / hanzi-writer-data, Arphic Public License.
