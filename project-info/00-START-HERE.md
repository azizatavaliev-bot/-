# WhatsApp Sales Bot — всё о продукте в одной папке

## Что это
Бот продаёт услугу в WhatsApp. Клиент пишет на номер, Claude отвечает как живой менеджер: задаёт уточняющие вопросы, мягко ведёт к покупке, собирает имя и удобное время связи.

## Как устроено (механика)
| Файл | Роль |
|------|------|
| `src/index.js` | Подключение к WhatsApp через Baileys (QR, как WhatsApp Web), приём сообщений, отправка ответов, автопереподключение |
| `src/ai.js` | Запрос к Claude API: системный промпт + история диалога → ответ (до 500 токенов) |
| `src/config.js` | **Единственное, что надо править под себя:** услуга, цена, часы работы, правила тона |
| `src/store.js` | История диалогов в памяти процесса, последние 20 сообщений на клиента |
| `.env` | `ANTHROPIC_API_KEY`, `CLAUDE_MODEL`, `OWNER_NOTIFY_JID` |

Полный код — в `02-CODE-SNAPSHOT.md`. Предыстория и решения — в `01-HISTORY.md`.

## Про localhost
🔥 У бота **нет веб-интерфейса и нет локального порта**. Он консольный: при первом запуске в терминале печатается QR-код, который сканируется в WhatsApp. Поэтому открывать в браузере нечего. Если нужна панель (диалоги, заявки, настройки), это отдельная задача.

## Запуск на Windows (PowerShell)
```powershell
# 1. Node.js 20+ :  winget install OpenJS.NodeJS.LTS   (потом открой новое окно PowerShell)
cd путь\к\репозиторию
npm install
Copy-Item .env.example .env
notepad .env          # вставь ANTHROPIC_API_KEY (в чат ключ не отправляй)
notepad src\config.js # название, услуга, цена, часы
npm start             # появится QR -> WhatsApp: Настройки > Связанные устройства
```
- Linux-команда `cp` в README = `Copy-Item` в PowerShell.
- Папка `auth_info\` хранит сессию WhatsApp. Не коммить и не отправляй никому: это доступ к номеру. Она уже в `.gitignore`.
- QR в обычном окне PowerShell иногда «ломается»: растяни окно или запускай в Windows Terminal.

## Известные ограничения
- ⚠️ Baileys — неофициальная библиотека: риск блокировки номера. Используй отдельный номер, не рассылай спам.
- История в памяти: после перезапуска диалоги забываются (сессия WhatsApp при этом сохраняется).
- `OWNER_NOTIFY_JID` объявлен в `.env.example`, но в коде **пока не используется**: заявки владельцу не пересылаются.
- Бот отвечает на любой личный и групповой текст, фильтра по группам нет.
- Нет защиты от флуда и лимита расходов на API.
- Читает только текст и подписи к фото, голосовые и документы игнорирует.

## Что делать дальше (рекомендую в таком порядке)
1. ✅ Заполнить `config.js`, запустить на тестовом номере, прогнать 10–15 живых диалогов.
2. ✅ Реализовать пересылку заявки владельцу (`OWNER_NOTIFY_JID`) и фильтр групп.
3. ✅ Сохранять диалоги в SQLite/Postgres и вести лог заявок для воронки.
4. 💡 Когда пойдёт объём: официальный WhatsApp Cloud API вместо Baileys.
