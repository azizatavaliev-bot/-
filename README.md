# WhatsApp Sales Bot

Бот для продажи услуги в WhatsApp с ИИ-диалогом на базе Claude.

## Как это работает

- Подключение к WhatsApp через [Baileys](https://github.com/WhiskeySockets/Baileys) (QR-код, как WhatsApp Web) — без нужды в верификации бизнеса в Meta.
- Ответы клиентам генерирует Claude по заданному вами описанию услуги, цене и правилам общения (`src/config.js`).
- История переписки с каждым клиентом хранится в памяти процесса для контекста диалога.

## Установка

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Скопируйте `.env.example` в `.env` и заполните:
   ```bash
   cp .env.example .env
   ```
   - `ANTHROPIC_API_KEY` — ключ API Claude (https://console.anthropic.com/)
3. Отредактируйте `src/config.js` — укажите название компании, описание услуги, цену, часы работы и при желании подстройте текст системного промпта.
4. Запустите бота:
   ```bash
   npm start
   ```
5. В терминале появится QR-код — отсканируйте его в приложении WhatsApp: **Настройки → Связанные устройства → Привязать устройство**.
6. После подключения бот будет автоматически отвечать всем, кто пишет на этот номер.

## Важно

- Используйте отдельный номер телефона для бота (не основной личный), так как неофициальные библиотеки подключения несут риск блокировки номера при массовых рассылках или подозрительной активности.
- Не используйте бота для спам-рассылок — пишите/отвечайте только тем, кто сам написал вам.
- Для продакшен-нагрузки замените память (`src/store.js`) на постоянное хранилище (Redis/Postgres) и рассмотрите переход на официальный WhatsApp Cloud API от Meta.
