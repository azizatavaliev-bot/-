# Автономный ИИ-агент в WhatsApp + Meta Ads

Работает на втором номере телефона, 24/7 на сервере (ноутбук не нужен):

- **Режим «Владелец»** — ты пишешь агенту со своего номера: «сколько расход за сегодня по направлению X», «останови кампанию Y», «напомни завтра в 9…», «каждый день в 21:00 присылай расход». Данные берёт из Meta Ads, изменения делает **только после твоего «да»**.
- **Режим «Клиентский»** — отвечает клиентам по базе знаний о бизнесе, при готовности купить / жалобе / неизвестном вопросе пишет тебе (`notify_owner`).
- **Панель настройки** — включение/выключение и режим для каждого чата, свои инструкции на чат, напоминания, песочница для теста, журнал действий.
- Если ты сам ответил клиенту с телефона — агент замолкает в этом чате на N минут (настраивается).

## Запуск локально (проверить)

```bash
npm install
cp .env.example .env     # заполни ANTHROPIC_API_KEY и ADMIN_PASSWORD
npm start                # панель: http://localhost:3000
```
В панели → «Подключение» появится QR. На втором телефоне: WhatsApp → Связанные устройства → Привязать устройство. Дальше: «Настройки» (бизнес, твой номер, часовой пояс) → «Тест» (проверить ответы) → «Чаты».

## Чтобы работало при закрытом ноутбуке

Нужен процесс, который не спит: VPS (~$4–6/мес: Hetzner, DigitalOcean, любой с Docker) либо Railway/Fly.io с постоянным диском. Vercel/serverless **не подходят** — WhatsApp держит постоянное соединение.

```bash
git clone <репозиторий> && cd <папка>
cp .env.example .env && nano .env
docker compose up -d --build
```
- `restart: always` — поднимется после сбоя и перезагрузки сервера.
- Том `/data` хранит БД и **сессию WhatsApp**. Не потеряешь том — QR сканировать повторно не придётся.
- Панель слушает только `127.0.0.1:3000`. Наружу — через HTTPS (Caddy: `agent.твойдомен.com { reverse_proxy 127.0.0.1:3000 }`) или SSH-туннель `ssh -L 3000:localhost:3000 server`. Пароль панели — длинный.

## Meta Ads: токен, который не протухает

Обычный пользовательский токен живёт 1–2 часа или 60 дней. Нужен токен **System User**:

1. business.facebook.com → Настройки бизнеса → Пользователи → **Системные пользователи** → Добавить (роль Admin).
2. Назначить активы: рекламный аккаунт (полный доступ) и, для создания объявлений, Страницу.
3. developers.facebook.com → Мои приложения → создать приложение типа Business → привязать к этому бизнесу.
4. Системный пользователь → **Сгенерировать токен** → выбрать приложение → срок **«Никогда»** → права `ads_read`, `ads_management` (+ `pages_read_engagement` для объявлений со Страницы).
5. Токен в `.env` → `META_ACCESS_TOKEN`; ID аккаунта (цифры из Ads Manager) → панель → Настройки → Meta Ads. Проверка: Подключение → «Проверить доступ».

Для **своих** аккаунтов проверка приложения (App Review) не нужна — хватает Standard Access. Токен может отозвать только человек: сменили пароль/удалили System User/сняли доступ к аккаунту. Если вдруг перестанет работать — панель покажет ошибку Meta в «Журнале».

## Защита от «ИИ натворил делов»

- Изменения рекламы — двухшаговые: инструмент только *предлагает* (summary), выполнение — после твоего **отдельного** сообщения. Модель не может подтвердить сама в том же ходе (проверено тестом).
- Лимит изменения бюджета за раз (по умолчанию 30%) и абсолютный потолок — Настройки → Meta Ads.
- Новые объявления создаются на паузе. Автозадачи по расписанию только читают/предлагают.
- Клиентские чаты не видят рекламу, пока явно не включишь флаг в карточке чата.
- Каждое действие пишется в «Журнал».

## ⚠️ Риски WhatsApp

Библиотека Baileys — неофициальная (эмуляция WhatsApp Web). Номер могут заблокировать, особенно при массовых исходящих или спаме. Правила: отдельный номер, только ответы тем, кто написал сам, никаких рассылок. Для серьёзного клиентского потока позже стоит мигрировать на официальный WhatsApp Business Cloud API (нужен верифицированный бизнес; владельческий режим останется тем же кодом агента).
