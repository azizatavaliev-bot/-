# Клава — тренажёр слепой печати

Статическое веб-приложение (один файл `index.html`, без сборки и бэкенда).

## Что умеет

- 12 уровней: от одной буквы домашнего ряда до целого абзаца текста
- RU и EN раскладки (физика клавиш одна и та же, меняются только символы)
- Цифровой ряд отдельным уровнем
- На экранной клавиатуре подсвечивается следующая клавиша цветом того пальца, которым её нужно нажать, плюс подпись «какой палец»
- Геймификация: XP, уровень игрока, звёзды за уровень (1–3, по скорости и точности), серия правильных нажатий (combo), прогресс сохраняется в localStorage
- Метрики в реальном времени: знаков/мин, точность, лучшая серия
- Тёмная/светлая тема, звук вкл/выкл

## Запуск локально

Просто открыть `index.html` в браузере — зависимостей нет.

Либо через любой статический сервер:

```bash
npx serve typing-trainer
```

## Деплой

Проект — статика без сборки, поэтому годится любой статический хостинг.

**Vercel:**

```bash
npx vercel --cwd typing-trainer
```

Framework Preset: **Other**, Build Command: пусто, Output Directory: `.`

**Netlify / GitHub Pages** — аналогично, просто указать папку `typing-trainer` как корень публикации.
