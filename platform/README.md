# AdOps — платформа для таргетологов

Каждый сотрудник подключает свои Facebook-аккаунты клиентов по API-токену. Платформа сама заполняет дневные отчёты, ищет проблемы, считает начисления и даёт ИИ-советника — в вебе и в Telegram-боте. Сначала работает отдельно, потом встраивается в основную систему.

## Что есть
- **Роли**: владелец (видит всю команду, деньги, настройки) и сотрудник (только свои проекты; проценты и оплату клиента сам менять не может).
- **Проекты**: аккаунт Facebook, фильтр кампаний по названию (несколько направлений в одном аккаунте), тип результата (лиды / переписки / покупки), оплата клиента, % исполнителю и владельцу, архив.
- **Авто-отчёты**: каждые 30 минут расход/показы/клики/результаты за вчера и сегодня; ручные правки (✎) не перетираются и сверяются с Facebook.
- **Анализ**: реклама встала, расход упал/вырос, цена результата +30%, 0 результатов при расходе, токен умирает, ручная правка ≠ Facebook.
- **Зарплаты**: проценты от оплаты клиента по месяцам, по сотрудникам и в целом по компании.
- **Токены**: хранятся зашифрованно (AES-256-GCM); проверка срока жизни; обмен короткого токена на 60-дневный; **инструкция** по бессрочному токену прямо в платформе (вкладка «Инструкция»).
- **Telegram-бот** (один общий): привязка по одноразовому коду из профиля; `/today /yesterday /projects /salary`, обычный текст → ИИ; утренняя сводка.
- **ИИ-советник**: видит отчёты и кампании, советует, что подкрутить; **меняет статус/бюджет только после «да»**, с лимитом изменения (по умолчанию ±30%).

## Запуск
```bash
cd platform
npm install
cp .env.example .env     # заполни ANTHROPIC_API_KEY, APP_SECRET, TELEGRAM_BOT_TOKEN, OWNER_PASSWORD
npm start                # http://localhost:3000
```
Для работы 24/7 — VPS + `docker compose up -d --build`, HTTPS через Caddy. Не Vercel/serverless: нужен постоянный процесс (бот, синхронизация).

**Первые шаги**: войти владельцем → «Команда» → создать сотрудников → «Проекты» → создать проект и подключить токен (инструкция в платформе) → сотрудники заходят и привязывают Telegram в «Профиль».

## Безопасность
- Данные изолированы по сотруднику на уровне запросов и инструментов ИИ (тест `изоляция`).
- Изменения рекламы двухшаговые: модель не может подтвердить сама (проверено тестом).
- Токены не возвращаются через API. Потеряешь `APP_SECRET` — токены придётся ввести заново.
- Вход: пароль (scrypt), HttpOnly-cookie, лимит попыток. Ставь за HTTPS.

## Встраивание в основную систему (позже)
Платформа — самостоятельный сервис с REST API (`/api/*`, cookie-сессия). Варианты: (1) iframe/ссылка + общий логин; (2) вынести `src/sync.js`, `salary.js`, `tools.js` как модули в основной бэкенд, а таблицы `projects`/`daily_reports` слить с вашими отчётами. Для этого нужно знать стек и схему основной системы.

## Ограничения MVP
- Нет создания новых креативов/кампаний (только статус и бюджет); нет голосовых.
- Зарплата без пропорции по дням для проектов, начатых/закрытых в середине месяца.
- Один Facebook-аккаунт на проект.
- Суммы в разных валютах не конвертируются — показываются отдельно.
- SQLite — достаточно для десятков сотрудников; для сотен — Postgres.

`npm test` — 9 тестов (изоляция, подтверждения, синхронизация, Telegram, API).
