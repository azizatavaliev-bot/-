# Видеоурок

Сюда кладётся бесплатный урок, который показывается между первым и вторым блоком.

- `lesson.mp4` — сам ролик. Формат MP4 (H.264 + AAC), горизонтальный 16:9
- `poster.jpg` — кадр-превью, который виден до нажатия play (необязательно)

Пока файла нет, вместо плеера показывается строка «Видеоурок скоро появится здесь».

## Если урок лежит на YouTube

Тогда файл не нужен — в `public/index.html` замените блок `<video>` на:

```html
<iframe class="lesson__frame" src="https://www.youtube.com/embed/ID_РОЛИКА"
        title="Бесплатный видеоурок" allowfullscreen></iframe>
```

Так надёжнее для длинного видео: YouTube сам раздаёт его и подбирает качество
под скорость интернета, а хостинг не платит за трафик.
