# Фото кейсов

`1.jpg` … `6.jpg` — карточки учеников из карусели. Суммы «Точка А / Точка Б»
уже впечатаны в сами изображения, поэтому страница ничего поверх не рисует.

Порядок файлов = порядок вывода на странице:

| Файл | Точка А | Точка Б |
|---|---|---|
| 1.jpg | 0 сом | 185 000 сом |
| 2.jpg | 0 сом | 424 000 сом |
| 3.jpg | 0 сом | 145 000 сом |
| 4.jpg | 30 000 сом | 550 000 сом |
| 5.jpg | 50 000 сом | 585 000 сом |
| 6.jpg | 0 сом | 158 000 сом |

Чтобы заменить кейс, положите новый файл под тем же именем. Формат вертикальный
(исходники 1080×1350). Если файла нет, карточка просто не показывается.
