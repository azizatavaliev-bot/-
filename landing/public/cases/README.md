# Фото кейсов

Сюда кладутся скриншоты учеников для блока «результаты» — те же, что в карусели.

- Имена файлов: `1.jpg`, `2.jpg`, `3.jpg`, `4.jpg`, `5.jpg`, `6.jpg`
- Формат вертикальный, примерно 3:4 (подойдёт обычный скрин сторис)
- Фото не кадрируется под квадрат: подписи «Точка А / Точка Б» рисует сама
  страница поверх градиента, поэтому лицо остаётся видно
- Суммы под каждым фото правятся в `public/index.html`, блок `<div class="cases">`

Пока файла нет, карточка показывает тёмную подложку с цифрами — вёрстка не ломается.
