# Фото кейсов

Здесь лежит один файл — `results.jpg`, тот самый скриншот-коллаж с результатами
учеников из карусели (точка А / точка Б).

Требования:

- Имя файла строго `results.jpg`
- Чёрный фон у скриншота — он сливается с фоном страницы, рамку страница не рисует
- Ширина исходника от **1600 px**. Картинка растягивается на всю ширину блока
  (до 720 px, на ретине это 1440 px), поэтому скрин с телефона в 1080 px
  будет заметно мылить
- Экспортировать лучше без пережатия: JPEG качеством 85–90 или PNG

Если файла нет, блок просто не показывается — вёрстка не ломается.
