# Видеоурок

Урок встроен в страницу прямо с Google Диска — файл на 130 МБ не имеет смысла
класть в репозиторий и раздавать с хостинга.

Блок находится в `public/index.html`, секция `id="lesson"`.

## Обязательное условие

Файл на Диске должен быть открыт по ссылке: **Настройки доступа → Все, у кого
есть ссылка → Читатель**. Без этого посетители увидят «Запросить доступ»
вместо плеера.

## Как перевести урок на YouTube

Надёжнее для платного трафика: YouTube сам подбирает качество под скорость
интернета и не имеет суточных лимитов на просмотры, в отличие от Диска.
Залейте ролик как «Доступ по ссылке» и замените `src` у `<iframe>` на:

```
https://www.youtube.com/embed/ID_РОЛИКА
```

Больше в коде менять ничего не нужно — разметка и стили те же.
