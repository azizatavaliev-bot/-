# Заявки в Google-таблицу

Сайт умеет отправлять каждую заполненную анкету строкой в вашу таблицу.
Ключи Google при этом в проекте не хранятся: таблица сама принимает запрос
через скрипт, опубликованный как веб-приложение.

## Настройка, один раз

1. Создайте таблицу на **sheets.google.com**
2. В меню **Расширения → Apps Script**
3. Удалите весь код в редакторе и вставьте этот:

```javascript
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  var data = JSON.parse(e.postData.contents);
  var headers = sheet.getRange(1, 1, 1, sheet.getLastColumn()).getValues()[0];

  // Первый запуск: создаём шапку из полей анкеты
  if (sheet.getLastRow() === 0 || headers.join('') === '') {
    headers = Object.keys(data);
    sheet.appendRow(headers);
  }

  sheet.appendRow(headers.map(function (name) { return data[name] || ''; }));
  return ContentService.createTextOutput('ok');
}
```

4. **Развернуть → Новое развёртывание** → тип **Веб-приложение**
5. Выполнять от имени: **я**. Доступ: **все**
6. Скопируйте выданный адрес вида
   `https://script.google.com/macros/s/AKfy.../exec`

## Подключение

В переменные окружения хостинга добавьте:

```
SHEETS_WEBHOOK_URL=адрес_из_шага_6
```

Перезапустите сервис. Следующая заявка появится в таблице строкой: дата,
имя, WhatsApp, возраст, город.

## Что учесть

- Доступ **«все»** означает, что адрес принимает POST без авторизации.
  Он не публикуется на сайте, но и секретом не является: кто-то знающий
  адрес сможет дописать строку в таблицу. Для анкеты лендинга это приемлемо;
  если нужна защита — добавьте в скрипт проверку пароля из тела запроса.
- Таблица — это дополнительный приёмник, а не замена. Заявки продолжают
  писаться в файл и уходить в Telegram, если те настроены.
- Меняете поля анкеты в `config.js` — очистите шапку таблицы,
  скрипт создаст её заново под новый набор.
