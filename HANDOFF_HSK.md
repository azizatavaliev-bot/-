## 2. Что сделано (по порядку)

1. Принят архив с приложением, проверен (`npm test`), опубликован как Artifact.
2. **Распознавание письма, офлайн.** Скелет штрихов → направленные признаки (4 ориентации, сетка 12×12) + число черт + порядок черт, когда число совпало. Образцы строятся из осевых линий черт (Make Me a Hanzi, Arphic Public License; 2972 знака). Точность на синтетических «рукописных» штрихах: ~98% первым, ~99,7% при проверке нужного знака; ближайший двойник засчитывается ошибочно ~7%. Живым почерком не проверялось.
3. Вкладки: «Письмо» (тетрадь прописи 米字格, режим «По памяти» для знака и предложения), «Тренировка» (чистый квадрат), «Доска» (16:9 и 9:16, клетки, строка пиньиня, ручка/кисть/ластик, диктант целого предложения с проверкой знаков и пиньиня, на весь экран).
4. **Анимация порядка черт** («Показать ответ», «Как писать»).
5. **«Мои слова»** (выбор слов) и **тесты по ним**: карточки, письменный (пиньинь + перевод), предложения, письмо знаков, вопросы с вариантами, всё подряд. Результаты пишутся в `S.selp`, журнал `S.tlog`; слово «освоено», если пройдено ≥2 видов.
6. **Репетитор (ИИ-чат)**: сервер `api/chat.js` (Claude API), контекст = выбранные и освоенные слова, журнал тестов, все уроки. Ответ JSON `{say,test}`; тест запускается кнопкой.
7. **Деплой на Vercel**, мобильная версия (viewport, нижнее меню, крупные кнопки).
8. **Словари из интернета:** HSK 3.0 уровни 1–6 и 7–9 (10 969 слов, открытый словарь `drkameleon/complete-hsk-vocabulary`, MIT) с русскими переводами (переведено агентами автоматически, не вычитано человеком).
9. **Учебники «新HSK教程» 1, 2, 3** (слова, переводы, примеры, грамматика): присланы пользователем текстом, сверены со словарём HSK. Том 1: 16 «уроков» (15 + имена собственные), 338 слов, 8 примеров. Том 2: 211 слов, 28 примеров (13 грамматических без пиньиня). Том 3: 18 уроков, 392 слова, 31 пример, 60 тем грамматики.
10. **Быстрый тест** («Тест», первая вкладка): источник слов (мои, НСК 1–3, HSK 3.0 по уровню и блоку, курс, выученное) → вид теста одним нажатием, ничего заранее выбирать не нужно.
11. **Репетитор собирает тесты локально**, без сервера и ключа: «10 карточек из урока 3 НСК 1», «квиз HSK 3.0 уровень 2 блок 3» (`tuLocal`). Остальное идёт на сервер.
12. **Письмо на карточках**: поле с двумя рядами клеток (слово и словосочетание), ручка/кисть/ластик, пиньинь; автопроверка при «Показать ответ». То же поле в «Письмо», «Тренировка», «Прописать знаки».
13. **«Подсказка» (3 уровня) и «Не знаю»** во всех видах тестов.
14. **Библиотека → практика слова**: кнопки «写 Писать» и «句 Предложения» открывают экран только с этим словом (пропись с образцом или по памяти, пиньинь, подсказка, предложения из учебников и спринта с «Собрать» и «Писать», своё предложение с проверкой, доской и вопросом репетитору). В итогах теста у ошибок кнопка «Практика».

## 3. Архитектура (коротко; подробности в CLAUDE.md)

- Один файл `index.html`: CSS + данные + логика. Рендер `views.<имя>()` → HTML-строка, клики через `data-a="<действие>"` → объект `act`, навигация `go(view)`. Состояние `S` в localStorage (`hskput.v1`), миграции в `normS()`.
- Данные внутри файла: `MEDS_SRC` (черты), `BANK_SRC` (HSK 3.0), `BOOK_SRC/BOOK2_SRC/BOOK3_SRC` (учебники), `UNITS_SRC/SPR_SRC` (курс приложения HSK 1–2: 31 тема, спринт 300 слов).
- Три списка слов во «Мои слова»: учебники (id `b…`, `c…`, `d…`), курс приложения, HSK 3.0 (id `n<ур>-<знак>`, уровень 7 = «7–9»).
- Тесты: сессия `TS` (`tsStart`, `itemsFor`, `tsItemHTML`, `tsSummary`). Поле письма `wpadHTML/wpadMount`, проверка `wpCheck/wpCheckNow`, распознавание `recPrep/recRank/recMatch/recVerify`, `recReady(extra)` строит образцы для знаков курса и выбранных слов.
- Сервер: `api/chat.js` (Vercel, Node). Переменные окружения: `ANTHROPIC_API_KEY` (обязательна для ИИ), `ACCESS_CODE` (код доступа, задан), `ANTHROPIC_MODEL` (по умолчанию `claude-sonnet-5-5`). Лимит 60 запросов в час на IP. Папка `materials/` читается сервером (сейчас пуста).

## 6. Открытые вопросы и ограничения

- **Ключ ИИ:** неизвестно, добавил ли пользователь `ANTHROPIC_API_KEY` в Vercel (после добавления нужен redeploy). Без него работают только локальные тесты. Код доступа хранится в переменной `ACCESS_CODE` в Vercel.
- **Полнота учебников:** в присланных текстах тома 2 и 3 уроки 12–15 и 12–18 сокращены (по словам самого источника), PDF не видели. Просить у пользователя блоки «生词» этих уроков. Том 4 и далее добавляются по той же схеме (`bookchk*.js` → `book*.txt` → встроить, см. CLAUDE.md).
- **Переводы HSK 3.0** автоматические, без вычитки; 7–9 уровни — 5606 слов.
- **Распознавание** проверено на синтетике; если пользователь жалуется на «верно написанный знак засчитан другим», собрать примеры и подстроить `REC.sg`, `REC.beta`, пороги `recVerify`. Есть кнопки «Засчитать вручную».
- Пиньинь-разметка учебников: в словаре расхождения только по смене тона (`bú`, `yì`, `yí`) оставлены как в учебнике; лёгкие тоны исправлены по словарю (`huí lai`, `tài yang` и т.д.).
- Репозиторий публичный; нового личного репозитория создать не удалось.
- Вопрос к пользователю, оставшийся без ответа: должен ли «Быстрый тест» без выбора брать выученные слова вместо учебника 1.
- Идеи на потом: PWA/установка на экран телефона, потоковые ответы репетитора, порядок черт с проверкой штрихов, импорт файлов HSK прямо в приложение, сброс/экспорт прогресса.
